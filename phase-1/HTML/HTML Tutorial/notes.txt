• Headings : <h1/>, <h2/>, <h3/>, <h4/>, <h5/>, <h6/>

• Paragraphs : <p/>

• Italic : <i/>

• Comments : <!-- -->
•Lists: <li/>
Unordered list <ul/>
Ordered lists <ol/>
• Forms: <form/>

• button : <button/>
