Explore learning paths

These sample paths are starting points, not strict schedules. Adapt them to your time and experience.

Web development

Learn to create websites by building up one layer at a time.

  1. HTML: structure and meaning
  2. CSS: layout, visual design, and responsive pages
  3. JavaScript: interaction and behaviour

Suggested practice task

Create a small three-section page, then improve its layout and usability.

Digital design

Learn to arrange content so people can understand and use it easily.

  • Visual hierarchy and spacing
  • Colour and readable typography
  • Accessible contrast and clear interaction states

Suggested practice task

Redesign a simple information card and explain the choices you made.
