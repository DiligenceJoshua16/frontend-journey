Explore Learning paths

These learning paths are starting points to every frontend technology. Study them and gain experience in time.

HTML

Learn to structure meaningful, accessible web pages.

What to learn

  1. HTML document structure and essential elements.
  2. Headings, paragraphs, lists, links, and images.
  3. Semantic HTML and document structure.
  4. Forms, labels, inputs, and buttons.
  5. Tables for appropriate tabular data.
  6. Metadata and basic SEO.
  7. Accessibility fundamentals.
  8. Embedding appropriate media and external content.

Skills to develop

  • Structure web pages using appropriate HTML elements.
  • Create meaningful navigation between pages.
  • Build accessible forms.
  • Organise content using semantic elements.
  • Write descriptive metadata and accessible image text.

Practice Projects

Here are some few project you can try to build on your own after learning HTML.

  • Personal profile page.
  • Multi-page learning resource website.
  • Accessible contact form.

Learning Milestone: Learners should be able to create a well-structured, multi-page website using semantic HTML without relying on CSS or JavaScript for its fundamental structure.

To learn more about HTML, visit MDN HTML learning resource

CSS

Learn to style web pages and create responsive user interfaces.

What to learn

  1. CSS syntax, selectors, and how styles are applied.
  2. The cascade, inheritance, and specificity.
  3. Colours, typography, backgrounds, and borders.
  4. The box model, margins, padding, and sizing.
  5. Display types and positioning.
  6. Flexbox and CSS Grid.
  7. Pseudo-classes and pseudo-elements.
  8. Responsive design and media queries.
  9. Transitions and basic animations.
  10. CSS organisation and reusable styling patterns.

Skills to develop

  • Create consistent visual designs.
  • Control spacing and layout.
  • Build responsive interfaces for different screen sizes.
  • Style forms, navigation, cards, and buttons.
  • Design visible keyboard-focus states.
  • Maintain readable and reusable CSS.

Practice projects

  • Styled multi-page website.
  • Responsive card layout.
  • Accessible form interface.
  • Responsive personal portfolio.

Learning milestone: Learners should be able to take a well-structured HTML website and transform it into a consistent, responsive interface.

To learn more about CSS, visit CSS learning resource

JavaScript

Learn to add behaviour and interactivity to web pages.

What to learn

  1. Variables, values, and data types.
  2. Operators and expressions.
  3. Conditional statements.
  4. Loops.
  5. Functions and scope.
  6. Arrays and objects.
  7. DOM selection and manipulation.
  8. Events and event handling.
  9. Form validation.
  10. Array methods and modern JavaScript syntax.
  11. Modules and code organisation.
  12. Asynchronous JavaScript, promises, and async/await.
  13. Working with APIs and JSON.
  14. Error handling and debugging.

Skills to develop

  • Respond to user interactions.
  • Validate and process form inputs.
  • Dynamically update page content.
  • Work with arrays and objects.
  • Fetch and display data from APIs.
  • Handle asynchronous operations and errors.
  • Organise JavaScript into maintainable modules.

Practice Projects

Practise your JavaScript skills by building interactive features and applications.

  • Interactive FAQ section.
  • Task manager.
  • Searchable resource directory.
  • Weather interface using an API.

Learning Milestone: Learners should be able to build interactive web interfaces, respond to user events, validate inputs, and retrieve and display external data.

To learn more about JavaScript, visit JavaScript learning resources.

TypeScript

Learn to use a type system to improve JavaScript development and maintain code reliability.

What to learn

  1. TypeScript fundamentals and setup.
  2. Basic types and type inference.
  3. Arrays, objects, and functions.
  4. Type aliases and interfaces.
  5. Union types and narrowing.
  6. Optional properties and literal types.
  7. Generics.
  8. Working with JavaScript libraries and type declarations.
  9. TypeScript configuration.
  10. Integrating TypeScript into frontend projects.

Skills to develop

  • Define types for application data.
  • Describe function parameters and return values.
  • Model objects and reusable data structures.
  • Identify potential type errors.
  • Use type narrowing to handle different values safely.
  • Maintain type-safe frontend code.

Practice Projects

Apply TypeScript concepts to projects that involve structured data and reusable application logic.

  • Typed task manager.
  • Searchable directory with structured data.
  • Type-safe API data display.

Learning Milestone: Learners should be able to build and maintain small applications using TypeScript's type system to describe data and identify potential errors during development.

To learn more about TypeScript, visit The TypeScript Handbook

React

Learn to build reusable, component-based user interfaces.

What to learn

  1. React fundamentals and project setup.
  2. JSX.
  3. Components and props.
  4. Rendering lists and using keys.
  5. Conditional rendering.
  6. State and event handling.
  7. Hooks, especially useState and useEffect.
  8. Sharing data between components.
  9. Forms and controlled inputs.
  10. Managing side effects.
  11. Fetching and displaying API data.
  12. Component organisation and reusable patterns.
  13. Routing and navigation.
  14. Testing fundamentals.

Skills to develop

  • Break interfaces into reusable components.
  • Pass data between components.
  • Manage interactive application state.
  • Handle forms and user events.
  • Display data from APIs.
  • Organise larger interfaces into manageable pieces.

Practice Projects

Build applications that combine reusable components, interactive features, and dynamic data.

  • Task management application.
  • Searchable product catalogue.
  • Interactive learning dashboard.
  • API-powered application.

Learning Milestone: Learners should be able to build a multi-component application with interactive state, reusable UI elements, and organised component logic.

To learn more about React, visit React Learn

Next.js

Learn to build and deploy web applications using React and Next.js.

What to learn

  1. Next.js fundamentals and project setup.
  2. App Router and project structure.
  3. Pages, layouts, and navigation.
  4. Server and Client Components.
  5. Data fetching.
  6. Loading and error states.
  7. Dynamic routes.
  8. Metadata and SEO.
  9. Forms and server-side operations.
  10. Caching and rendering fundamentals.
  11. Application deployment.

Skills to develop

  • Structure multi-page applications.
  • Choose appropriate rendering approaches.
  • Fetch and display data.
  • Handle loading states, errors, and dynamic routes.
  • Improve application metadata and discoverability.
  • Deploy functional web applications.

Practice Projects

Apply Next.js concepts to applications that require structured navigation, dynamic content, and deployment.

  • Multi-page learning platform.
  • Blog or documentation website.
  • Resource directory with dynamic routes.

Learning Milestone: Learners should be able to create, organise, and deploy a small Next.js application with multiple routes, appropriate rendering strategies, and reliable loading and error states.

To learn more about Next.js, visit Next.js documentation
